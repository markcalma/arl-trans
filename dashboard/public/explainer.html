ARL-Trans · Operations Dashboard

How it works — a guide to every panel, term, and button

Overview

What is this dashboard?

Every morning, an automation workflow (WF1 — Water Report) runs and processes the daily Amercare spreadsheet. It updates ARL-Trans's container tracking systems, calculates last free days, and flags any containers at risk of per diem charges. This dashboard shows the results of that run — what was processed, what needs attention, and what's in the queue.

The dashboard is read-only — it reflects what the automation did. The only interactive action is the ✓ Done button on flagged exceptions.
Panel 1

Run Status Bar

Shows when the last automation run happened, whether it succeeded, and a quick summary of what was processed.

Last run
The date and time the automation last ran. Runs are scheduled daily, typically early morning.

Status indicators

Success — all steps completed without errors
Warning — completed, but with minor issues (e.g. fallback data used for some rows)
Error — one or more steps failed
No data — no run has been recorded yet

Summary numbers

Processed
Total number of rows read from the spreadsheet this run.
Added
New containers that did not exist in the system before this run.
Updated
Existing containers whose data (ETA, LFD, status) was refreshed.
Skipped
Rows the automation could not process — usually due to missing data or exceptions. See the Exception Queue for details.
Panel 2

Per Diem Alerts

Containers are listed here when their Last Free Day is within 5 days. These need to be picked up, moved, or released before charges begin (or escalate).

Per Diem
Daily storage charges billed by the terminal or port when a container sits past its Last Free Day. Costs accumulate each additional day.
LFD
Last Free Day — the last date the container can remain at the terminal without incurring per diem charges. After this date, daily fees apply.
SSL
Steamship Line — the ocean carrier that owns the container. Examples: COSCO, EVERGREEN, MAERSK, MSC, OOCL.
Days
How many days remain until (or since) the LFD. Color-coded by urgency:
1 day Urgent — charges may already be accruing
2–3 days Act soon
4–5 days Heads up — monitor this week
Panel 3

Exception Queue

Containers the automation flagged and could not process normally. Two types: ones that need Gary's review, and ones that are purely informational.

Reuse Load
A container number that appeared more than once in the spreadsheet — a potential duplicate entry. The automation flagged it because processing it twice could corrupt the data. Gary reviews it to determine if it's a real duplicate or a data error, then clicks ✓ Done to dismiss it.
Exam Flag
A container that has been flagged by US Customs for examination. It is physically held at the port pending inspection. The automation skipped it intentionally — no update is possible until the container is released. No action needed from Gary. The label "Under customs hold — row skipped" confirms this. It will clear on its own once the hold is lifted and the next run processes it.

The Done button

✓ Done
What it does
Marks a Reuse Load exception as reviewed and removes it from the queue for the rest of the day's run.
Does it persist?
No. The dismissal is per-run. The next time the automation runs and sends a new report, the queue resets — any unresolved exceptions in the new data will reappear.
Exam flags
Exam flags do not have a Done button. They clear automatically once the customs hold is lifted.
Panel 4

Container Table

Full list of all containers tracked in the current run. Filterable by terminal location, sortable by date.

Container #
The unique alphanumeric ID stamped on the physical shipping container — 4 letters + 7 digits (e.g., FCIU9906716).
Location
The terminal or warehouse where the container currently is. Examples: Exton, Stockton, Carson, NJ, Oakland, Ontario, Vacaville.
ETA
Estimated Time of Arrival — the date the container is expected to arrive at the destination.
LFD
Last Free Day — same as in Per Diem Alerts. The deadline before storage charges begin.
SSL
Steamship Line — the ocean carrier that owns the container.
PO
Purchase Order number — ties the container to a specific order in ARL-Trans's system.

Controls

Location filter
Dropdown to show only containers at a specific terminal. Select All to see everything.
Sort: LFD
Sorts by Last Free Day — containers closest to their deadline appear first. Good for prioritizing pickups.
Sort: ETA
Sorts by Estimated Time of Arrival — containers arriving soonest appear first.
Show all / Show less
The table shows 10 rows by default. Click Show all N containers to expand the full list, or Show less to collapse it again.
Panel 5

Run Log

A step-by-step record of everything the automation did during the last run. Collapsed by default — click the header to expand.

▸ / ▾
Click the Run Log header to expand or collapse the log entries.
Time
The timestamp (HH:MM:SS) when each step ran, relative to the start of the run.

Step status colours

ok
Step completed normally. No action needed.
warning
Step completed but with a caveat — for example, "LFD fallback used — 3 rows (blank free days)" means 3 containers had no free-day data in the spreadsheet so a default was applied.
error
Step failed. If the overall run status is Error, look here to find which step broke.
